# Проверка локального MVP

Дата: 16 октября 2026 года.

## Окружение

- Frontend: установленный стек из `package.json`, Node.js 24, pnpm 11.25.0.
- Backend: существующий `KvartirkaBackend`, pnpm 10.34.5, NestJS и PostgreSQL.
- Основная development-БД содержала двух пользователей и пустые прикладные таблицы. Её миграции актуальны; seed повторно не запускался.
- Для изменения данных и проверки сессий использована отдельная локальная БД `kvartirka_frontend_qa_20261016` с двумя временными пользователями. Это настоящий backend с теми же миграциями и DTO, без mock API.
- Браузер: Chromium в браузере Codex. Проверялись development server и собранная версия через Vite preview с явным proxy к QA-backend.
- После приёмки временные серверы на портах 3001, 5174 и 4173 остановлены; QA-БД и файл временных учётных данных удалены. Основные frontend/backend оставлены запущенными на 5173/3000.
- Финальный `/health` основного backend вернул HTTP 200. Основная БД сохранила двух пользователей и ноль целей, пополнений и покупок. Основное приложение открыто в браузере на экране входа.

## Статические проверки

`pnpm lint`, `pnpm typecheck`, `pnpm format:check`, `pnpm build` — пройдены после исправлений lifecycle диалогов и сетевого поведения.

Новые зависимости не добавлялись, версии и lock-файл не изменены. Существующий стиль форматирования пользователя сохранён: четыре пробела.

| Вход | Неверный пароль даёт единое сообщение; правильные данные устанавливают сессию и открывают приложение |

| Покупки | Создание со всеми полями, редактирование и удаление через реальные endpoints работают |

| Фильтры | Комната, категория и статус фильтруют список; комбинация без результата отличается от пустой БД; сброс возвращает список |

## Матрица расчётов

Чистые функции проверены разовым запуском через Node.js без установки test framework и без постоянной test suite:

- пустая история и будущий срок;
- пополнения до текущего месяца и в текущем месяце;
- точное достижение и превышение цели;
- срок в текущем месяце и в прошлом месяце;
- достижение цели до начала месяца;
- округление плана вверх до копейки: 10 001 копейка на три месяца → 3 334 копейки;
- переход из октября в ноябрь;
- ввод с пробелами и запятой, одна копейка, отрицательная сумма, лишние десятичные знаки, экспоненциальная запись и граница безопасного JSON integer;
- корректный високосный день и невозможные календарные даты.

## Инженерные решения по итогам проверки

- Диалоги остаются смонтированными при закрытии, а состояние формы создаётся заново при открытии. Это сохраняет механизм возврата фокуса Mantine и сбрасывает поля/ошибки между редактированиями.
- Если исходный элемент удалён, фокус возвращается к основному содержимому страницы.
- GET-запросы получают AbortSignal. Смена сессии очищает Query cache и загружает новый документ; старый runtime не продолжает работу в новой сессии.
- Сохранения не повторяются автоматически и не помещаются в offline-очередь. Ошибка загрузки ресурса и ошибка формы обрабатываются отдельно.
- `prefers-reduced-motion` отключает пользовательские transitions/animations через global CSS; сложные Motion-анимации в первый запуск не добавлялись.
